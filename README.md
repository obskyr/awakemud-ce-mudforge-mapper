# An AwakeMUD CE Mapper for You

This script enables the built-in map widget in [MudForge](https://mudforge.org/), a cross-platform MUD client, to be compatible with the venerable [AwakeMUD CE](https://www.awakemud.com/). Mostly. MudForge’s mapper doesn’t lay out rooms very well (you may have to run **`mapper relayout confirm`** semi-regularly), and this script currently doesn’t support zones. It *does,* however, enable using **`mapper find …`** to pathfind/speedwalk to places, which is mighty helpful.


## Installation

In MudForge:

1. Open the Plugin Manager (<kbd>Ctrl</kbd> ⁠+ <kbd>P</kbd>).
0. Click <kbd>Add Repository</kbd>.
0. Paste this repository’s URL (`https://github.com/obskyr/awakemud-ce-mudforge-mapper`) into the “Repository URL” box.
0. Click <kbd>Validate Repository</kbd>.
0. Click to toggle on “Trusted Repository”.
0. Click <kbd>Add Repository</kbd>.
0. Switch to the Plugin Manager’s “Browse” tab.
0. Find and click on the download button for “AwakeMUD CE Mapper”.
0. Switch to the Plugin Manager’s “Installed” tab.
0. Click the cog icon by AwakeMUD CE Mapper.
0. Click to toggle on “Auto-update”.

And you’re done! Now, the map will be filled in **as long as the map widget is open.**
